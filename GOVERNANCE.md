# Governance

This repository is maintained by one person, the copyright holder `NOTICE` names; "the
maintainer" in its documents is that person, not a team.

The protocol this package implements is governed by `GOVERNANCE.md` in `loquitur-protocol`: how
the specification changes, its compatibility classes and its change-proposal register. This
package follows the specification and does not change it. A change here that needs a different
rule starts as a change proposal there.

In this repository, the maintainer accepts a change that affects the verifier's reports, its
exported surface, the package contents or a public claim only with tests and documentation. The
maintainer refuses a change that:

- takes in code or documents another repository owns;
- exposes private evidence or material of an unpublished repository;
- claims production use, an audit, compliance, finality or valuation correctness;
- changes public behavior without tests and documentation.
