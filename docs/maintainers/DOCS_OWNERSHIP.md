# Documentation ownership

This repository documents the `@loquitur/verify` package:

- installing, building and checking the package locally;
- what the offline verifier checks, its scope and its limits;
- the package boundary and the publication guard.

It does not document a server, private evidence material, third-party material other than the
test data `NOTICE` credits, or an HTTP client, which this package does not have. It makes no
claim of a stable public contract.

The rules the verifier implements are the specification's, in `loquitur-protocol`. This
repository cites them by document and section and does not restate them as its own.

How to run the checks: [`testing.md`](testing.md).
